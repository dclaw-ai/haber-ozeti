AI Ideas of the Day

Multi-agent systems

Multirun: ten isolated Claude Code agents try the same task, then get diffed

A developer's open-source framework runs the same task through 10 unattended Claude Code agents, each with its own git worktree and database branch, with 3 running in parallel. The fan-out took about 50 minutes; all 10 runs finished and passed the checks, and all ten converged on the same core schema while splitting on choices like cascade versus set-null deletes. The author reads the splits as places where the prompt was underspecified, and notes ten runs is a small sample.
