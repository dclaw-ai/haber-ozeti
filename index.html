Personal AI system

A second brain where Claude and Codex share one Obsidian memory

Saksham Arora keeps an Obsidian vault in git, where an agent files new items from an inbox folder, and startup hooks load a hot file of current deadlines, 60+ memory files and weekly session summaries. Claude and Codex share context through an agent-sync hook, three retrievers (ChromaDB, LightRAG, CLIP) sit behind a router, and 11 hooks plus 6 scheduled jobs handle indexing and stale-tracker checks. Changes from phone agents auto-merge only if they touch the inbox folder, and the post openly notes a search-index job silently failed for 120 nights.

AutoDoc-Sentinel: an autonomous repo agent that treats the LLM as a last resort

The author built a single autonomous agent for code repositories that translates code locally with tree-sitter first, asks an LLM only for low-confidence cases, and calls Devin at most once or twice a day within a hard daily budget.
