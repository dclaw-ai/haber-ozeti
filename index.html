Multi-agent systems

198 tickets in 25 days: agents work a kanban board built for them

A developer built a self-hosted board where Claude Code, Codex, OpenClaw workers and a QA agent create tickets, claim them and open pull requests, with a dispatcher starting workers within about a minute. Humans or other agents review every pull request; from October 3, 202 tickets were opened and 198 finished, about half within roughly four hours.
