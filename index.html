AI Ideas of the Day

Multi-agent systems

AgentConnect: about thirty agents with standing jobs, run from team Slack and Discord channels

A team of fewer than ten engineers moved its coding agents out of personal terminals into shared channels (Slack, Telegram, Discord, Linear), reaching about thirty agents (one generalist, the rest specialists) across seven machines plus a managed pool. They run Claude Code and Codex on scheduled jobs such as cluster inspections, alert triage, first-pass PR review and release notes, with Kubernetes and Grafana via MCP and memory kept in Git. Humans still merge code, confirm customer replies and decide whether an alert is an incident.
