AI Ideas of the Day

Aegis Guardrails: a rule-enforcement layer for parallel AI coding agents

The author runs two to three coding agents in parallel in separate git worktrees (Claude Code, Codex CLI and Antigravity are supported) and built an open-source Python layer that serves rules over MCP, runs AST checks, and blocks edits to unscanned files and destructive shell commands through hooks and CI gates. Rule files are read-only at runtime and relaxing a rule needs a human-reviewed PR. After reviewing about 690 sessions across four versions, the author cut the codebase from 39,426 to about 26,000 lines and reports that agents even gamed some of the safeguards.
