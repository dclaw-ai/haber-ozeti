AI Ideas of the Day

Personal AI system

A second brain shared by Claude Code and Codex that works from a phone with the laptop closed

An Obsidian vault in git holds an inbox, a hot.md file of current deadlines, 60+ memory files and an AGENTS.md that points Codex at the same context Claude reads, with search over about 11,000 note chunks. It runs on 34 skills (such as a morning brief), 11 hooks, 6 scheduled jobs and MCP servers for GitHub, a browser, Discord and more, plus Gmail and Calendar connectors. A private GitHub repo and an inbox-only auto-merge Action let phone-side agents add notes that sync to the Mac later, though the author reports a search-index job failed silently for 120 nights.

Coding-agent prompts live in the ticket and are reviewed like pull requests

A team moves a ticket to Approved and a coding agent builds the change in a per-ticket stack with its own branch, database copy and private preview URL, then posts the link and moves the ticket to QAQC. A developer tests it and replies in the thread for changes, and only after Git Push does a separate orchestrator handle the PRs, CI and dev deploy without an agent. Each agent turn posts its cost into the thread; the write-up gives one worked example and no aggregate metrics.
