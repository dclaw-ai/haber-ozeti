Personal AI system

An Obsidian vault redesigned so Claude Code checks notes but the owner writes them

Takashi Abe keeps an Obsidian vault with fleeting notes, clippings and AI conversations, and a custom /zettelkasten skill in Claude Code adds links and tags. The AI only checks claims against primary sources, argues the strongest counterargument and suggests related notes, while he writes each permanent note himself, with verification run as a batch command from the vault folder. He says his old vault produced only 21 permanent notes in 3.5 years, and the redesign is still untested end to end.
