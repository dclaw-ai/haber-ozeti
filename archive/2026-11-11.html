Second brain

An Obsidian vault that stores what you understood, not the code

The author keeps a vault of mental models, trade-offs, discarded alternatives and decision records, linked to AI coding sessions through hooks and skills. Each project runs in learn, log or off mode, and in learn mode the agent quietly saves concepts you ask about and offers a 10–12 question exam at milestones. The author reports qualitatively that codebases stay familiar weeks later and concepts carry across projects.

AI in operations

Flexport uses AI to suggest customs codes, with a broker checking every one

Flexport's AI suggests a 10-digit tariff code and links the CBP rulings behind it, and a licensed customs broker reviews each code by hand before filing. AI also writes code that encodes customer-specific delivery rules, which an expert signs off. The CEO says freight volumes rose 40% while headcount grew 5%, and that Flexport's customs filing error rate was 0.2% last year.

Multi-agent systems

DEV's loops of coding agents merged 351 pull requests in three weeks

Since October 19, a self-hosted OpenHands hub has run specialised loops for performance, tests, Rust ports, errors and dependencies, with up to eight in parallel on 10-minute ticks. A router rotates between Claude, GPT and Gemini models, a reviewer on a different model family checks risk, and low-risk PRs auto-merge after CI. The author reports average Rails request time falling from about 70ms to 16ms; the figures are self-reported.
