AI Ideas of the Day

Second brain

An LLM wiki in Obsidian that Claude Code maintains with a lock that protects its log

An Obsidian vault and git repo split into raw sources the agent only reads, a wiki it writes with decisions, failures and project context, and handoff notes between sessions. Each page records whether it was confirmed by running it, stated by a person or inferred, and the agent writes only on five plain commands. The author reports 166 pages in about 11 weeks, and locking the index stopped the log losing 77 of 120 entries in a concurrency test.

Multi-agent systems

bigpickle-brain: three agents draft priced proposals for a small agency

A research agent reads a prospect's site and competitors, a proposal agent prices the work from the agency's own service list, and a code check plus reviewer agent can send it back for one rewrite. It is hand-written on the Anthropic API (or local models via Ollama) with a fixed stage order and Markdown memory people can correct in Obsidian. One real bakery run took 16 minutes and produced an approved AUD 4,600–8,000 proposal.
