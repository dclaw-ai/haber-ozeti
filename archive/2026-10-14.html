AI Ideas of the Day

Talking to a smart home through Claude Code

A home-lab writer enabled Home Assistant's built-in MCP server, chose which devices to expose and registered it with Claude Code using one command. Claude can now check device states, switch lights and run existing scripts such as a bedtime routine from a chat. It does not get admin access and does not replace the existing automations.

Scrimshaw Jukebox: a browser player for AI-composed adventure-game music

Simon Willison asked Claude Opus 5.5 in claude.ai to design a simple text music format and build an artifact that plays it, aiming for a Monkey Island feel. The result has six original tracks, a pixel-art scene that reacts to the music and an editable piano roll, all running in the browser.

web-edit: edit server files from your phone without exposing secrets

Wanting to edit a credentials file from his phone without sending it through an LLM, Simon Willison had Codex with GPT-6 Astra build a small Python web app. It runs over Tailscale and offers a file browser, uploads, image previews and a CodeMirror 6 text editor chosen for better mobile support.
