AI Ideas of the Day

Multi-agent systems

Spawn: a multiplayer game run by agents that ship to production hourly

Founder Jacob Sansbury describes a game where players prompt an in-game AI, Savi, to reshape the world, while a swarm of agents edits live code and ships to production hourly. Savi files bugs herself and an agent triages each one, with monitors waking an agent that owns the incident and rollbacks taking 30 seconds. He says it costs over $3 million in tokens a month; Simon Willison doubts the approach would suit higher-stakes software.
